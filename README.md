# project_generator
A generator for creating new golang based service.

## Generate a project with bash script

Project generation with script is simple, but cannot support some advancer functions, such as more complicated code generation.

```
    $ sh tools/go-project-gen.sh test_project
```

## Generate a project with golang script

Project generation with script is simple, but cannot support interactive generation.

```
    $ go run tools/generator.go
```
